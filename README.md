# HomeFit

Flutter-приложение для домашних тренировок с офлайн-статистикой, челленджами и системой прогресса.

## Что реализовано

- MVVM + Provider
- Офлайн-хранение статистики и результатов через SharedPreferences
- 8 предустановленных тренировок с уровнями сложности
- Экран дашборда с прогрессом, streak и тренировкой дня
- Экран тренировки с таймером упражнений/отдыха и автопереходом
- Экран результата после завершения
- Экран статистики пользователя

## Запуск

```bash
flutter pub get
flutter run
```
